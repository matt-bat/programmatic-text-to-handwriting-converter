# Contributor guides

Welcome. Pick the guide that matches the change you want to make.

- [Local development](development.md) covers setup, project structure, tests, and pull requests.
- [Rendering changes](rendering-changes.md) covers seeded output, visual checks, and engine tests.
- [Documentation changes](documentation.md) covers writing style, links, screenshots, and source-of-truth rules.

Read the main [contribution guide](../../CONTRIBUTING.md), [safety policy](../../SAFETY.md), and [code of conduct](../../CODE_OF_CONDUCT.md) first.

If the idea changes project scope, ask in GitHub Discussions before implementing it. Issues are best for a confirmed bug or a piece of work with clear acceptance criteria.
