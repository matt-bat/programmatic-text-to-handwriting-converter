# Support

## Using Scribble Lab

Start with the [README](README.md) and [operations guide](docs/operations.md). Search existing GitHub issues before opening a new one.

Use a bug report for reproducible application problems. Use a feature request for improvements that remain within the identity-free boundary. Do not attach private documents, handwriting samples, or signatures.

Sensitive vulnerabilities should be reported privately by following [SECURITY.md](SECURITY.md).

## Support development

If Scribble Lab is useful to you, you can optionally [support Matthew Bateman on Ko-fi](https://ko-fi.com/matt0bat). Financial support does not purchase support priority, project control, warranties, or special access.
