# Third-party assets

## Hershey coordinate data

- Packaged files: `src/assets/hershey-script-data.js` and `src/assets/hershey-print-data.js`
- Included faces: Hershey Simplex Script, Hershey Complex Script, and Hershey Simplex Sans (`futural`)
- Runtime size: approximately 36 KB
- Status: public domain
- Original author: Dr. Allen V. Hershey, U.S. National Bureau of Standards
- Source dataset: `techninja/hersheytextjs`, `hersheytext.min.json`
- Source URL: <https://github.com/techninja/hersheytextjs>
- Original dataset SHA-256: `73709473c12b3ea48b29a8167ef4f84ea7340cfa3f44e65fc0194690edf41ceb`
- Script faces extracted: 2026-08-16
- Print face extracted: 2026-08-17

NIST documentation identifies the Hershey font collection, including the script and sans-serif faces, as public-domain fonts distributed as part of NBS Special Publication 424. The source repository separately declares its original Hershey JSON coordinate data public domain. Only the three coordinate arrays used by the app are packaged. None of the repository's MIT-licensed renderer code is included.
